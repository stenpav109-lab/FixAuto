## Вариант 8

Исходный объект: Фиксация проезда автомобилей.

Свойства: дата (`гггг.мм.дд`, без кавычек), номер автомобиля
(строка в кавычках).

## Формат входных строк

- Фиксация <дата> "<номер>"
- Скорость <дата> "<номер>" <скорость>
- Камера <дата> "<номер>" "<id камеры>" <широта> <долгота>


- дата — `гггг.мм.дд`, без кавычек;
- номер и id камеры — в двойных кавычках;
- скорость, широта, долгота — дробные числа с точкой;
- свойства разделяются одним или несколькими пробелами.

### Примеры


- Фиксация 2024.09.15 "А123БВ777"
- Скорость 2024.09.16 "В456ЕК99" 87.5
- Камера 2024.09.17 "М789НР197" "CAM-42" 55.7558 37.6173


## Пример вывода


- Фиксация проезда: дата = 2024.09.15, номер = А123БВ777
- Фиксация проезда: дата = 2024.09.16, номер = В456ЕК99, скорость = 87.5 км/ч
- Фиксация проезда: дата = 2024.09.17, номер = М789НР197, камера = CAM-42, координаты = (55.7558, 37.6173)
