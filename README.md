## Вариант 8

Исходный объект: **Фиксация проезда автомобилей**.

Свойства: дата (`гггг.мм.дд`, без кавычек), номер автомобиля
(строка в кавычках).

## Формат входных строк

```
Фиксация <дата> "<номер>"
Скорость  <дата> "<номер>" <скорость>
Камера    <дата> "<номер>" "<id камеры>" <широта> <долгота>
```

- дата — `гггг.мм.дд`, без кавычек;
- номер и id камеры — в двойных кавычках;
- скорость, широта, долгота — дробные числа с точкой;
- свойства разделяются одним или несколькими пробелами.

### Примеры

```
Фиксация 2024.09.15 "А123БВ777"
Скорость 2024.09.16 "В456ЕК99" 87.5
Камера 2024.09.17 "М789НР197" "CAM-42" 55.7558 37.6173
```


## Пример вывода

```
== Из строки ==
Фиксация проезда: дата = 2024.09.15, номер автомобиля = А123БВ777
Фиксация проезда: дата = 2024.09.16, номер автомобиля = В456ЕК99, скорость = 87.5 км/ч
Фиксация проезда: дата = 2024.09.17, номер автомобиля = М789НР197, камера = CAM-42, координаты = (55.7558, 37.6173)

== Из файла ==
Фиксация проезда: дата = 2024.09.15, номер автомобиля = А123БВ777
Фиксация проезда: дата = 2024.09.16, номер автомобиля = В456ЕК99, скорость = 87.5 км/ч
Фиксация проезда: дата = 2024.09.17, номер автомобиля = М789НР197, камера = CAM-42, координаты = (55.7558, 37.6173)
Фиксация проезда: дата = 2023.01.01, номер автомобиля = О321РС750
```

## Обработка ошибок

Программа корректно обрабатывает некорректные строки и не прерывает
разбор при ошибке в одной из них. Ошибки собираются в `RecordParser.errors`
и выводятся отдельно с указанием номера строки.

Иерархия исключений:

- `ParseError` — базовое исключение;
- `MissingFieldError` — не найдено обязательное поле;
- `InvalidDateError` — некорректная дата;
- `InvalidPlateError` — некорректный номер автомобиля;
- `UnknownTypeError` — неизвестный тип объекта.

Пример вывода ошибок:

```
Ошибки:
Строка 4: Некорректная дата: day is out of range for month
Строка 5: Некорректный номер: 'XYZ'
Строка 6: Неизвестный тип: 'неизвестно'
```

## Архитектура (SOLID)

- SRP — каждый класс отвечает за одну задачу:
  - `FieldExtractor` — извлечение и валидация полей;
  - `ObjectFactory` — создание объектов нужного типа;
  - `RecordParser` — оркестрация разбора и накопление ошибок;
  - `errors` — иерархия исключений.
- OCP — добавление нового типа объекта выполняется расширением
  `ObjectFactory.ALIASES` без изменения существующих классов.
- LSP — `VehiclePassWithSpeed` и `VehiclePassWithCamera`
  взаимозаменяемы с `VehiclePass`.
- ISP / DIP — классы используют только те методы друг друга,
  которые им нужны; зависимости передаются явно.

## Тесты

Модульные тесты в `test_parser.py` покрывают:

- `FieldExtractor` — корректные и некорректные даты, номера, числа;
- `ObjectFactory` — создание всех трёх типов + ошибки;
- `RecordParser` — успешный разбор, пустые строки, накопление ошибок.
